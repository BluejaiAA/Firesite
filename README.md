# Firesite

Professional fire risk assessment software for UK fire safety professionals.

## Live

- Marketing site: https://firesite-weld.vercel.app
- App: https://firesite-weld.vercel.app/app.html

## What it is

Firesite is a single-purpose web application that helps responsible persons, fire risk assessors and competent advisers complete fire risk assessments under the Regulatory Reform (Fire Safety) Order 2005 and produce PAS 79-1:2020 compliant reports.

The product supports a structured 16-section assessment workflow with photo evidence, an action plan, and a generated PDF report.

## Status

Active, in production. Closed-source / proprietary.
